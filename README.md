# Mitos: mundo abierto

Juego de exploración de mitología griega para jugar en el celular, sin conexión. Cinco personajes, cada uno con un poder; algunos lugares solo los alcanza el personaje correcto.

Estado: campo de pruebas jugable (Pegaso y Minotauro). Reglas y mapa de archivos en `CLAUDE.md`.

Para probarlo en una computadora: servir la carpeta con cualquier servidor estático y abrir `index.html`. Teclas: flechas o WASD para moverse, espacio para saltar, E o Shift para el poder, 1 a 5 para elegir personaje, Esc para el menú.
